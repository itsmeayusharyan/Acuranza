Standard build: new 'Install Full build from APK' under Settings → Financial tools → SMS transaction tracking. Pick the Full APK from your storage and Acuranza verifies it (package name, signature, version) and starts Android's own install confirmation — the same installer-session path third-party installers use. Google's security check still runs; any prompt it raises is yours to answer. Nothing is disabled or hidden; the standard build keeps no SMS permission of its own.
